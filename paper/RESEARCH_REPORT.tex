\section{Executive Summary}
%% ============================================================

\textbf{Paper title:} Does Cost-Efficiency Travel? What Agent Leaderboards Can Predict About Cost Across Workloads.

\textbf{Venue:} AgenticOS Workshop, NeurIPS 2026 (double-blind, 6 pages + appendix).

\textbf{Core thesis:} Every unconditioned aggregate we can compute from public agent data --- raw cost ranks, success-adjusted efficiency, failure premiums --- conflates which workloads were attempted with how agents behaved on them.

\textbf{Three studies:}
\begin{enumerate}[nosep]
\item \textbf{Cost-rank portability:} Raw dollar-cost ranks transfer across HAL benchmarks (mean $\rho=0.84$) but are absorbed by stable displayed-label cost propensity ($R^2=82.0\%$, residual ranks insignificant). CPS is less portable (mean $\rho=0.59$).
\item \textbf{Scaffold burden:} At fixed task and model, OpenHands uses 15\% fewer turns/tool calls than SWE-agent ($N=977$ matched pairs, $p=0.197$ for resolved status).
\item \textbf{Failure-burden:} The ``expensive failure'' premium is not detected under exact task matching: 107 discordant pairs, failed side heavier only 47--52/107 ($p\geq0.25$), normalized ratio 0.98--1.06, MDE=15pp at 80\% power.
\end{enumerate}

\section{Primary HAL Study Results}
%% ============================================================

\subsection{Data and cohort}

Frozen snapshot: 242 evaluations across 9 benchmarks, 11 scaffolds, 29 model labels. Fixed scaffold: HAL Generalist Agent. 6 benchmarks with $\geq5$ shared labels: CORE-Bench Hard, GAIA, SciCode, ScienceAgentBench, SWE-bench Verified Mini, TAU-bench Airline. Final cohort: 86 rows, 25 labels.

\subsection{Cost-rank portability}

\begin{itemize}[nosep]
\item Raw dollar-cost Spearman $\rho$: 0.74--0.93 across high-overlap pairs (mean 0.84)
\item All survive permutation + Holm correction
\item Cost-propensity model: $R^2 = 82.0\%$ (adjusted 72.7\%), 30 parameters, 56 residual df
\item After removing label+benchmark fixed effects: residual cost ranks insignificant everywhere
\end{itemize}

\subsection{Success-adjusted efficiency (CPS)}

\begin{itemize}[nosep]
\item Mean CPS $\rho = 0.59$ vs raw cost 0.84
\item Survives permutation + Holm only for CORE--GAIA (0.87), CORE--TAU (0.83), GAIA--TAU (0.78)
\item GAIA--SWE-mini: raw-vs-CPS gap 0.60 [0.14, 1.13]
\end{itemize}

\subsection{LOBO held-out prediction}

\begin{itemize}[nosep]
\item Succeeds: CORE ($\rho=0.78$), GAIA (0.87), SWE-mini (0.90), TAU (0.83)
\item Fails: SciCode ($-0.17$), ScienceAgentBench ($-0.64$)
\end{itemize}

\subsection{Frontier membership}

No label appears on all 6 frontiers under any definition (discrete, hull, 5\% tolerance). ``No universal winner'' is robust.

\section{External Matched Trace Study}
%% ============================================================

\subsection{Scaffold burden ($N=977$)}

\begin{itemize}[nosep]
\item OpenHands/SWE-agent median ratio: 0.85 for turns [0.82, 0.87], 0.85 for tool calls [0.82, 0.86]
\item OpenHands lower on 69.7\% of pairs
\item Resolved status: no detected difference ($p=0.197$)
\end{itemize}

\subsection{Failure-burden ($N=107$ discordant pairs)}

\textbf{Naive cross-task view (replicates folklore):}
\begin{itemize}[nosep]
\item OpenHands: failed/resolved turns ratio 1.21 [1.07, 1.36]
\item SWE-agent: turns 1.19 [1.07, 1.35], characters 1.33 [1.11, 1.54]
\end{itemize}

\textbf{Task-matched view (dissolves the premium):}
\begin{itemize}[nosep]
\item Sign test: failed side heavier 47--52/107 on every metric ($p\geq0.25$)
\item Scaffold-normalized ratio: 0.98--1.06, CIs span 1
\item MDE at 80\% power: p1=0.65 (15pp); observed 0.47--0.53 well below
\item 95\% CI [0.37, 0.57] raw, [0.43, 0.63] normalized
\end{itemize}

\textbf{Power analysis (binomial test, $N=107$, $\alpha=0.05$):}
\begin{itemize}[nosep]
\item Critical values: reject if $k\leq42$ or $k\geq65$
\item Power at p1=0.55: 0.14; p1=0.60: 0.48; p1=0.65: 0.85
\item MDE at 80\% power: p1=0.65
\end{itemize}

\textbf{Scope:} One model (MiniMax-M2.5), four-shard nonrandom sample, character/turn proxies not tokens/dollars. Rules out strong premiums but not modest ones.
